Run it in your browser

A model writes one theme file; the harness says whether it runs. Here the harness runs in this page: you see the theme move and the gates’ verdict, worded as the native harness words it, in seconds.

  1. Copy the prompt (and the contract it refers to) into any model.
  2. The model answers with one file: a Zig theme or a WGSL kernel.
  3. Drop or paste the answer anywhere on this page. A .zig is compiled here by Zig 0.17.0 itself, as WebAssembly.
  4. Watch it run, and read the gates: PASS or FAIL, and why.

2Grade a Zig theme

Zig compiles in this page. Drop or paste a .zig theme anywhere here. The Zig 0.17.0 compiler, built to WebAssembly, type-checks and builds it in your browser, and the harness’s gates grade it; nothing is uploaded. The first compile downloads the compiler and the part of the standard library a compile reads (4.6 MB), kept for the next visit. Two things differ from the native harness. Gate 1 is type-checked for wasm64, not the app’s aarch64-macos (this compiler has no aarch64 backend). Its usize is 64 bits too, so expected type 'u32', found 'usize', the leaderboard’s most common compile error, fails here as it does natively. Code that needs macOS or libc is not covered. Gate 8: the module comes from Zig’s own wasm backend, without LLVM, SIMD or threads. Scalar code runs at up to a few times the native harness’s frame time; @Vector code is tens of times slower (Tutorial_Tides: about 60× LLVM’s wasm in Chrome). The frame time here is this build’s, and the official Gate 8 is the native harness’s: submit a pull request below.

GPU track prompt · written for this page

      
Write a single WGSL theme for Argus’s WebGPU runtime, following the contract below (the prelude is prepended to your file). The entry point is `@compute @workgroup_size(8, 8) fn argus_draw(@builtin(global_invocation_id) id: vec3u)`, writing every pixel with `textureStore(argus_out, gid, vec4f(colour, 1.0))`; add `argus_init` / `argus_step` and a `// @argus state WxH` line if your simulation needs persistent state. It must pass the Argus Metal harness’s checks, as run in the browser: compiles, runs at 320x200, no NaN or Inf, more than 100 distinct pixels, at least 2,000 pixels visibly animated between frame 1 and frame 120 (dt = 1/30 s), and under 8,333 µs average GPU time per frame at 1920x1200. Simulate a real physical or mathematical system. Output ONLY the complete .wgsl source file.
