What it is

Every Desktop Space gets its own live theme

Swipe from one Space to the next and you swipe from a quasar to a night beach to a marbling bath. A theme is one file: a Metal kernel on the GPU or a Zig file on the CPU.

Drop it on a Space from the menu bar and Argus compiles it on the spot; save an edit and it reloads in a second. No engine, no assets: a pixel grid, a clock and a frame budget. Argus draws only the Spaces you can see.

Themes are native code. Only run themes you trust.

Install

One line on macOS, from source on Linux

macOS

Apple silicon
curl -fsSL https://raw.githubusercontent.com/gke0op/argus/main/install.sh | sh

Downloads the latest release, checks its SHA-256, installs it to ~/Applications/Argus and opens it. Run it again to update. The app isn’t notarized: read the script or use the zip.

Then click the eye in the menu bar and drop a theme on a Space.

Linux

experimental · X11
sudo apt install git make curl
git clone https://github.com/gke0op/argus.git && cd argus
make zig                              # the pinned Zig 0.17.0, into .toolchain/
make linux THEME=themes/Cygnus_A.zig  # or THEME=themes/cpu/Tutorial_Tides.zig
./argus-linux                         # Ctrl+C or kill to stop

One static Zig binary, no libc or X libraries, that draws one theme as your X11 desktop. Tested on Ubuntu 24.04, arm64 and x86_64. Metal themes need a CPU port first; Tutorial Tides has one.

github.com/gke0op/argus MIT licence. Build from source on a Mac: make zig && make run.

How it works

One file per theme, three ways to run it here

.metal · .zig

Themes are single files

A .metal theme is a compute kernel over every pixel, with optional state kept between frames. A .zig theme is a State with init, step and draw: one allocation, then none.

GPU

Metal → WGSL on WebGPU

Each of the nine Metal themes has a one-to-one WGSL translation with the app’s frame semantics. At frame 120, every pixel is within 3/255 of Metal’s.

CPU

Zig → wasm on Workers

Zig themes compile unchanged to SIMD128 wasm and split rows across Worker threads. The 8 gates are the native harness’s own code, and Tides’ final frame is bit-identical to native.

Cygnus A

Kerr light paths, checked

The black hole’s Metal kernels are ported to WGSL one for one, and its Zig runs as a 79 KB wasm module. 99.996% of pixels match the app’s frame, none by more than 2 levels, and the shadow’s edge matches Bardeen’s analytic curve to 1.79e-5 M.

In the app, 49 physics claims sit in a test ledger, all passing. What is computed and what is chosen.

Limits

What this page can’t match yet

At full Retina and 120 Hz, Lizard Island, Roulette Chrome and Night Tide drop some frames; their simulations keep the 30 Hz tick. Tides in wasm takes 17–18 ms a frame against 15.3 ms natively, so here it fails Gate 8. Measured in Chrome 157 on an Apple M3.
